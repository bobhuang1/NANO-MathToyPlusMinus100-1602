# NANO-MathToyPlusMinus100-1602

Arduino Nano math-practice toy: addition and subtraction drills within 100 on a 16x2 LCD, press the button to reveal the answer; a beep marks each new question and each reveal. Needs an I2C LCD library that provides `LiquidCrystal_I2C_Arduino.h` (see `.github/workflows/compile.yml`).
